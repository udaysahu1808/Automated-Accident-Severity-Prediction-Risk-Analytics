# 📖 Project Overview

Road traffic accidents remain one of the leading causes of injuries, fatalities, and economic losses across the world. Analyzing accident data is essential for identifying high-risk conditions and implementing preventive safety measures.

This project demonstrates how **Automated Exploratory Data Analysis (Auto-EDA)** tools can rapidly analyze accident datasets with minimal coding effort.

The project evaluates and compares three widely used Auto-EDA tools:

- **YData Profiling**
- **AutoViz**
- **DTale**

The notebook covers complete data understanding, automated profiling, visualization, interactive exploration, comparative evaluation, business insights and strategic recommendations.

This project also establishes a strong foundation for future Machine Learning models that can predict accident severity and support intelligent traffic management systems.

---

# 🎯 Problem Statement

Road traffic accidents result in thousands of fatalities and injuries every year. Traditional exploratory data analysis requires considerable time and effort before meaningful insights can be extracted.

The objective of this project is to automate the EDA process using modern analytics tools to quickly understand accident data, identify major risk factors, evaluate data quality, and support data-driven decision-making for improving road safety.
